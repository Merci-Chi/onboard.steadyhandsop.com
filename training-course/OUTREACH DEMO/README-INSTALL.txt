STEADY HANDS OUTREACH — LOCAL OVERLAY TRAINING

Copy the 7 site files in this ZIP into the SAME folder as your existing index.html, replacing those files only. No GitHub, SQL, or backend setup.

Open index.html through a local web server (recommended):
  cd "/path/to/OUTREACH DEMO"
  python3 -m http.server 8000
  http://localhost:8000/index.html

Training starts automatically. The walkthrough operates on the existing index.html, call.html and sales.html. It is fictional and simulates the call, preview, calendar, and pipeline lesson without contacting real services. Associate name is optional. Exit training to explore the demo.

Note: Opening a local file:// URL may interfere with normal scripts; use the web server command above.
